# Maryam Profile Site

Interactive personal brand website for Maryam Sayed Husain Alawi.

Tech stack:
- React + Vite
- Framer Motion for motion and reveal effects
- Lucide React icons
- Custom design system and typography in CSS

## Local Preview

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Open the local URL shown in the terminal.

## Build Check

```bash
npm run build
```
